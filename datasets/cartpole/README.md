# CartPole expert demonstrations

CartPole does not require a downloaded dataset. Its data is generated by
running an expert in the `CartPole-v1` environment.

## State and action

Each CSV row records the state before an action and the outcome of that action:

```text
episode_id, timestep,
cart_position, cart_velocity, pole_angle, pole_angular_velocity,
expert_action, reward, terminated, truncated
```

Actions are:

- `0`: push left
- `1`: push right

The expert follows the project plan:

```text
expert_action = 1[theta + 0.6 * theta_dot + 0.02 * x_dot > 0]
```

The default generated dataset contains 100 episodes from seeds 0--99. The
metadata JSON records the simulator backend, row count, episode-length summary,
action counts, and SHA-256 checksum.

## Generate

From the Final Project directory:

```bash
python3 datasets/cartpole/generate_expert_dataset.py
```

Backend choices:

- `auto`: use Gymnasium if installed, otherwise use the compatible built-in
  simulator.
- `gymnasium`: require the official `CartPole-v1` implementation.
- `builtin`: use the dependency-free implementation included in the script.

To regenerate with Gymnasium:

```bash
python3 -m pip install -r requirements-datasets.txt
python3 datasets/cartpole/generate_expert_dataset.py --backend gymnasium
```

This file is only the initial expert dataset for behavior cloning and DAgger
initialization. DAgger rounds must generate additional trajectories online,
mix expert and learner control using beta, and query the expert on visited
states.
