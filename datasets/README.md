# Datasets

This directory contains the two data sources required by the project plan.

## Stanford OCR

`ocr/letter.data` is a fixed, real structured-prediction dataset. Each word is
an episode and each letter is one timestep. The current letter image and the
previous letter form the learner state; the current true letter is the expert
action.

## CartPole

CartPole is a simulator rather than a downloadable fixed dataset. The initial
expert demonstrations in `cartpole/` are generated by rolling out the
rule-based expert from the project plan. During DAgger, the training program
must query that expert on newly visited learner states and append those labels
to the aggregated training data.

Run `python3 datasets/validate_datasets.py` from the Final Project directory to
check both prepared datasets.
